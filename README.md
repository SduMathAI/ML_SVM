# ML_SVM

This repository stores materials related to SVM lecture notes and related assets.

Current contents:

- `Lecture_Note/`: Git submodule pointing to `https://github.com/Tristan-sdu/ML_SVM_note.git`
- `Exercise_solution/`: Git submodule pointing to `https://github.com/EdisonLiu520/ML_Chap6_Exercises.git`

Notes:

- Clone with submodules:
  `git clone --recurse-submodules https://github.com/SduMathAI/ML_SVM.git`
- Initialize and update submodules if already cloned:
  `git submodule update --init --recursive`
- Update all submodules to their latest remote versions:
  `git submodule update --remote --recursive`
