# processed 数据分析报告（正式整合版）

## 1. 报告目的

本报告针对项目目录 `processed/` 中的 MRI 数据进行系统统计与结构分析，目的是回答 3 个问题：

1. 当前数据集的标签、时间点和样本规模是什么；
2. 这些 `.nii.gz` 文件的空间尺寸、体素分辨率和数据类型是否一致；
3. 该数据集是否适合直接用于基于 SVM 的脑 MRI 分类建模。

## 2. 数据位置与文件格式

数据目录为：

`processed/`

文件格式为：

`*.nii.gz`

这是一种常见的医学影像格式，叫作 `NIfTI`，适合保存三维脑 MRI 数据。

在 Python 中，常见的读取方式为：

```python
import nibabel as nib

img = nib.load("xxx.nii.gz")
data = img.get_fdata()
```

其中：

1. `img` 包含影像头信息和空间信息；
2. `data` 是真正的三维体素数组。

## 3. 命名规则

文件名统一满足如下结构：

`数据源 + 受试者编号 + 类别标签 + 时间点 + 场强`

例如：

`ADNIADsim+002_S_0619+AD-m00-1.5T.nii.gz`

可以解析为：

1. 数据源：`ADNIADsim`
2. 受试者编号：`002_S_0619`
3. 类别标签：`AD`
4. 时间点：`m00`
5. 扫描场强：`1.5T`

当前目录中的文件都可以按这一规则解析，没有发现命名异常。

## 4. 数据规模统计

### 4.1 总体规模

`processed/` 目录共包含 `2989` 个 MRI 文件。

按类别统计如下：

| 类别 | 文件数 | 受试者数 |
| --- | ---: | ---: |
| AD | 577 | 172 |
| MCI | 1598 | 380 |
| NORMAL | 814 | 218 |

可以看到：

1. `MCI` 样本数最多；
2. `AD` 样本数最少；
3. 数据集整体存在一定的类别不平衡。

### 4.2 时间点分布

按时间点统计如下：

| 时间点 | 文件数 |
| --- | ---: |
| m00 | 768 |
| m06 | 728 |
| m12 | 677 |
| m18 | 284 |
| m24 | 482 |
| m36 | 50 |

按“类别-时间点”细分如下：

| 类别 | m00 | m06 | m12 | m18 | m24 | m36 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| AD | 172 | 163 | 143 | 0 | 99 | 0 |
| MCI | 378 | 354 | 335 | 284 | 222 | 25 |
| NORMAL | 218 | 211 | 199 | 0 | 161 | 25 |

这些数字说明：

1. `m00` 样本量最大；
2. 三类标签都覆盖 `m00`；
3. `m18` 只出现在 `MCI`；
4. `m36` 只在 `MCI` 和 `NORMAL` 中出现。

因此，最适合作为第一版建模起点的是：

**基线时间点 `m00`。**

### 4.3 完整随访受试者情况

同时拥有 `m00/m06/m12/m24` 四个时间点的受试者统计如下：

| 类别 | 完整受试者数 |
| --- | ---: |
| AD | 91 |
| MCI | 202 |
| NORMAL | 152 |

这说明该数据集不仅适合做基线分类，也为后续纵向分析预留了可能性。

## 5. 影像头信息一致性

对全部样本的头信息统计发现：

| 项目 | 统计结果 |
| --- | --- |
| 图像尺寸 | `133 x 129 x 170`，全部一致 |
| 体素间距 | `1.0 x 1.0 x 1.0 mm`，全部一致 |
| 数据类型 | `int8`，全部一致 |
| 仿射矩阵 | 全部一致 |
| 场强 | 全部为 `1.5T` |

这说明：

1. 数据已经处于统一空间；
2. 图像尺寸和分辨率高度一致；
3. 预处理负担明显低于原始 DICOM 数据；
4. 非常适合直接进入机器学习流程。

## 6. 基线样本像素值特征

以下统计基于全部 `m00` 样本：

| 类别 | m00 样本数 | 平均零值比例 | 平均均值 | 平均标准差 | 最小值下界 | 最大值上界 | 非零体素均值 P95 | 非零体素均值 P99 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| AD | 172 | 0.5617 | -0.9130 | 13.0846 | -122 | 127 | 29.84 | 52.37 |
| MCI | 378 | 0.5620 | -0.7794 | 12.8150 | -118 | 127 | 29.64 | 50.08 |
| NORMAL | 218 | 0.5626 | -0.6113 | 12.4495 | -123 | 127 | 29.21 | 46.90 |

这些结果说明：

1. 大约 `56%` 的体素值为 `0`，可视为背景区域；
2. 数据包含正值和负值，说明它更像经过预处理后的结果，而不是原始灰度值；
3. 三类数据的整体数值分布相近，适合统一建模。

## 7. 对建模设计的意义

从数据分析角度看，本项目最合理的第一步是：

1. 先只取 `m00`；
2. 先做 `AD vs NORMAL`；
3. 再扩展到 `MCI vs NORMAL`、`AD vs MCI` 和三分类。

这样做的原因是：

1. `m00` 是样本最多且定义最清楚的时间点；
2. `AD vs NORMAL` 标签边界最清晰；
3. 最适合与课程中的 SVM 理论建立对应关系；
4. 最容易避免多时间点带来的数据泄漏风险。

## 8. 结论

`processed/` 数据已经具备了直接开展 SVM 建模的条件：

1. 文件命名规范，标签可直接解析；
2. 图像尺寸、体素间距和仿射矩阵高度一致；
3. 数据规模足够支持基线分类实验；
4. `m00` 子集最适合作为课程项目的主实验数据集。

因此，本项目的数据分析结论可以概括为：

**最推荐的起点是基于 `processed/` 中 `m00` 基线 MRI 数据，开展 `AD vs NORMAL` 的 SVM 分类研究。**
