# 实验结果总结（正式整合版）

## 1. 实验设置概览

当前实验统一采用以下设置：

1. 数据来源：`processed/`
2. 主实验时间点：`m00`
3. 主模型流程：`StandardScaler + PCA + SVM`
4. 划分方式：受试者级别 `80%` 训练集、`20%` 测试集
5. 参数选择：训练集内部 `5-fold StratifiedGroupKFold`

| 任务 | 总样本数 | 训练集 | 测试集 |

## 2. 主课题结果

主课题定义为：

**`AD vs NORMAL @ m00`**

对应测试集结果如下：

| 模型 | 最优参数 | Accuracy | Balanced Accuracy | Precision | Recall | F1 | ROC-AUC | 支持向量数 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Linear SVM | `C = 0.1` | `0.7692` | `0.7721` | `0.7105` | `0.7941` | `0.7500` | `0.9071` | `97` |
| RBF SVM | `C = 10, gamma = scale` | `0.7564` | `0.7507` | `0.7273` | `0.7059` | `0.7164` | `0.8730` | `279` |

主课题结果说明：

1. 主课题在测试集上取得了较稳定的分类效果；
2. 线性核在当前任务上略优于 RBF 核；
3. 线性模型的支持向量数量明显更少，更适合做课程主线讲解。

## 4. 核函数比较结论

从当前结果看，并不能得出“RBF 一定优于线性核”的结论。

更准确的说法是：

1. 在 `AD vs NORMAL` 上，线性核更好；
2. 在 `MCI vs NORMAL` 上，RBF 略优；
3. 在 `AD vs MCI` 上，RBF 的 Accuracy 更高，但整体仍然较难；
4. 在三分类任务中，线性核略稳。

因此，本项目非常适合用来说明：

**模型越复杂，不等于结果一定越好。**

## 5. 任务难度结论

从当前实验表现看，任务难度大致为：

1. 最容易：`AD vs NORMAL`
2. 中等：`MCI vs NORMAL`
3. 最难的二分类：`AD vs MCI`
4. 最复杂：`AD/MCI/NORMAL` 三分类

这说明模型表现不只由算法决定，也由任务本身的可分性决定。

## 6. 支持向量与主课题解释

主课题线性 SVM 的支持向量数量为：

- 总数：`97`
- 每类：`[40, 57]`

RBF SVM 的支持向量数量为：

- 总数：`279`
- 每类：`[125, 154]`

这组结果很适合用于课程讲解：

1. 线性模型已经取得较好效果；
2. 真正决定分类面的，只是训练样本中的一部分；
3. 线性模型用更少的支持向量达到了更好的表现。

## 7. 参数 `C` 的实验现象

在线性 SVM 上扫描 `C` 得到如下结果：

| C | Accuracy | Balanced Accuracy | F1 | ROC-AUC | 支持向量数 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `0.01` | `0.7821` | `0.7901` | `0.7733` | `0.9138` | `101` |
| `0.1` | `0.7692` | `0.7721` | `0.7500` | `0.9071` | `97` |
| `1` | `0.7692` | `0.7721` | `0.7500` | `0.9071` | `97` |
| `10` | `0.7692` | `0.7721` | `0.7500` | `0.9071` | `97` |
| `100` | `0.7692` | `0.7721` | `0.7500` | `0.9071` | `97` |

需要注意的是：

1. 测试集上 `C = 0.01` 的表现略高；
2. 但交叉验证选出的主课题线性最优参数是 `C = 0.1`；
3. 这正说明参数选择必须依赖训练集内部验证，而不是直接看测试集。

## 8. 最终结论

如果只保留一个最核心的实验结论，可以写成：

**在 `processed/` 的 `m00` 基线 MRI 数据上，`AD vs NORMAL` 是最适合作为主课题的任务；在线性 SVM 下，测试集 Accuracy 为 `76.92%`，Balanced Accuracy 为 `77.21%`，ROC-AUC 为 `0.9071`。**
