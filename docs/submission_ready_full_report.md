# 基于 Lecture_Note 的脑 MRI 支持向量机建模报告（正式整合版）

## 1. 研究题目

**基于 ADNI 脑 MRI 基线数据的 AD 与 NORMAL 分类研究：以 PCA-SVM 为主线分析最大间隔、支持向量、核函数与软间隔方法**

## 2. 研究背景

阿尔茨海默病（AD）的早期识别具有重要临床意义。脑 MRI 影像能够反映脑结构变化，因此适合作为疾病辅助识别的数据基础。支持向量机（SVM）是经典的监督学习方法，尤其适用于中小样本、高维特征建模场景。结合课程 `Lecture_Note` 第 6 章中的“间隔、对偶问题、核函数、软间隔与正则化”等内容，本项目选择脑 MRI 的 SVM 分类任务作为课程项目主线，既具有明确的理论对应性，也具有实际可操作性。

## 3. 数据分析

### 3.1 数据来源与格式

项目数据位于 `processed/`，文件格式为 `.nii.gz`，属于 NIfTI 医学影像格式，适合保存三维脑 MRI 数据。

文件命名结构为：

`数据源 + 受试者编号 + 类别标签 + 时间点 + 场强`

例如：

`ADNIADsim+002_S_0619+AD-m00-1.5T.nii.gz`

### 3.2 数据规模

`processed/` 目录共包含 `2989` 个 MRI 文件。

按类别统计如下：

| 类别 | 文件数 | 受试者数 |
| --- | ---: | ---: |
| AD | 577 | 172 |
| MCI | 1598 | 380 |
| NORMAL | 814 | 218 |

按时间点统计如下：

| 时间点 | 文件数 |
| --- | ---: |
| m00 | 768 |
| m06 | 728 |
| m12 | 677 |
| m18 | 284 |
| m24 | 482 |
| m36 | 50 |

由于 `m00` 样本量最大，且三类标签都覆盖该时间点，因此最适合作为第一版实验的基线数据。

### 3.3 数据一致性

对头信息统计发现：

1. 全部图像尺寸一致：`133 x 129 x 170`
2. 全部体素间距一致：`1.0 x 1.0 x 1.0 mm`
3. 全部数据类型一致：`int8`
4. 全部仿射矩阵一致
5. 全部场强均为 `1.5T`

这说明数据已经高度标准化，适合直接进入机器学习流程。

### 3.4 数据分析结论

综合来看，当前数据集具备以下特点：

1. 标签清晰，命名规范；
2. 空间结构一致，预处理门槛低；
3. `m00` 最适合作为主实验时间点；
4. 最推荐的主任务是 `AD vs NORMAL`。

## 4. 研究任务设计

### 4.1 主课题

本项目的主课题定义为：

**`AD vs NORMAL @ m00`**

选择该任务作为主线的原因是：

1. 类别边界最清晰；
2. 最容易体现最大间隔分类思想；
3. 最适合比较线性核与 RBF 核；
4. 最适合把理论内容与实验代码结合起来讲解。

### 4.2 扩展任务

为体现模型在不同任务上的表现差异，本项目还设置了以下扩展任务：

1. `MCI vs NORMAL`
2. `AD vs MCI`
3. `AD/MCI/NORMAL` 三分类

## 5. 理论与 Lecture Note 的对应关系

本项目与讲义第 6 章内容的对应关系如下：

1. `6.1 间隔与支持向量`
   对应主课题中“为什么 SVM 要找最大间隔超平面”

2. `6.2 对偶问题、KKT`
   对应支持向量在最终分类面中的决定性作用

3. `6.3 核函数`
   对应线性核与 RBF 核的实验比较

4. `6.4 软间隔与正则化`
   对应参数 `C` 对分类边界和泛化能力的影响

5. `6.6 核方法扩展`
   对应三分类与扩展任务分析

## 6. 方法设计

### 6.1 数据预处理

本项目采用一条轻量但稳定的预处理流程：

1. 读取 `.nii.gz` 三维 MRI；
2. 对非零体素做强度裁剪；
3. 对单个样本做标准化；
4. 下采样到 `32 x 32 x 32`；
5. 展平成一维特征向量。

### 6.2 特征与模型

模型流程为：

`StandardScaler + PCA(100) + SVM`

比较的模型包括：

1. Linear SVM
2. RBF SVM

### 6.3 数据划分与验证

为了避免数据泄漏，本项目按受试者级别进行训练测试划分。

主课题中：

1. 总样本数：`390`
2. 训练集：`312`
3. 测试集：`78`

参数选择方式为：

1. 训练集内部 `5-fold StratifiedGroupKFold`
2. 测试集只用于最终评估

### 6.4 评估指标

实验使用以下指标：

1. Accuracy
2. Balanced Accuracy
3. Precision
4. Recall
5. F1-score
6. ROC-AUC

## 7. 主课题实验结果

### 7.1 主课题测试集结果

| 模型 | 最优参数 | Accuracy | Balanced Accuracy | Precision | Recall | F1 | ROC-AUC | 支持向量数 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Linear SVM | `C = 0.1` | `0.7692` | `0.7721` | `0.7105` | `0.7941` | `0.7500` | `0.9071` | `97` |
| RBF SVM | `C = 10, gamma = scale` | `0.7564` | `0.7507` | `0.7273` | `0.7059` | `0.7164` | `0.8730` | `279` |

### 7.2 主结果解释

主课题结果说明：

1. 线性 SVM 已经能够在测试集上取得较好的分类效果；
2. 线性核在当前任务上略优于 RBF 核；
3. 线性模型更简单，也更适合作为课程讲解主线。

如果只保留一句最核心的主结果，可以写成：

**在线性 SVM 下，`AD vs NORMAL @ m00` 的测试集 Accuracy 为 `76.92%`，Balanced Accuracy 为 `77.21%`，ROC-AUC 为 `0.9071`。**

## 9. 核函数与软间隔分析

### 9.1 核函数比较

本项目并没有支持“RBF 一定优于线性核”的简单结论。

更准确的结论是：

1. 在主课题上，线性核更优；
2. 在某些较难任务上，RBF 核略有优势；
3. 更复杂的核函数不等于一定更好。

### 9.2 参数 `C` 的实验现象

在线性 SVM 中扫描 `C` 后，观察到如下现象：

1. 不同 `C` 会影响测试集表现与支持向量数量；
2. `C = 0.01` 在这次测试切分中略优；
3. 但正式参数选择仍应以训练集内部交叉验证为准。

这与讲义中的软间隔与正则化思想是一致的。

本项目基于 `processed/` 中的脑 MRI 数据，围绕 `AD vs NORMAL @ m00` 构建了一条完整的 SVM 建模流程。通过数据分析、特征构建、模型训练、参数选择与测试集评估，可以得到以下结论：

1. `processed/` 数据已经具备直接建模条件；
