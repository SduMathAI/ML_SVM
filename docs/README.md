# Docs README

`docs/` 目录已经整理为一套精简后的最终文档集合。

## 当前保留的核心文档

### `submission_ready_data_report.md`

作用：

- `processed/` 数据分析正式版
- 适合用于“数据理解”和“为什么这样选主课题”的部分

### `experiment_results_summary.md`

作用：

- 当前实验结果总结
- 适合快速查看主课题与扩展任务的核心数字

### `submission_ready_full_report.md`

作用：

- 完整课程项目报告
- 适合直接作为整合版提交文档

### `script_quick_guide.md`

作用：

- 当前脚本说明
- 适合快速知道应该跑哪个脚本、讲哪些脚本

## 当前 docs 的建议使用顺序

1. 先看 `submission_ready_data_report.md`
   先理解 `processed/` 数据是什么

2. 再看 `experiment_results_summary.md`
   再看实验结论和关键结果

3. 然后看 `submission_ready_full_report.md`
   把数据、方法、结果整合起来

4. 最后看 `script_quick_guide.md`
   确认代码和脚本入口
